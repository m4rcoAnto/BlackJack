# BlackJack

A terminal Blackjack implemented in Java, with a Python version planned
for comparison.

I know Java reasonably well, so I started there; the Python version comes
next as a way to learn how that language wants things done, rather than
translating Java line by line.

## Status

Work in progress.

- [x] `Card` — name, suit and point value
- [x] `Deck` — 52 cards, random draw with removal
- [x] `Dealer` — initial deal, alternating player and dealer
- [ ] Hand scoring, with aces counting 1 or 11
- [ ] Hit / stay loop
- [ ] Dealer draws to 17
- [ ] Win conditions
- [ ] Python version

## Run

Open in IntelliJ and run `Main`.
